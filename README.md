# URLデコードコピー (URL Decode Copy) - C-Button & Context Menu Edition

Google Chrome上で動作し、表示しているウェブサイトの「タイトル」と「デコード済みのURL」を素早くクリップボードにコピーするための拡張機能です。
ツールバーの専用ボタン（Cバッジ）または右クリックメニュー（コンテキストメニュー）からワンクリックで実行できます。

## 概要

本拡張機能は、ウェブサイトのURLに含まれるエンコーディング（日本語のURLなど）を読みやすくデコードし、さらに不要なトラッキングパラメーターを除去した状態で、ページのタイトルと共にコピーします。

特に、タイトルの取得が難しい特定のFAQサイトやニュースサイトにおいて、最適なテキストを抽出する独自のロジックを搭載しています。

また、Googleサポートページでは英語版・日本語版のタイトルを直接取得できる機能を追加しました。

## 主な機能

1. **URLのクリーンアップとデコード**
   - URLエンコードされた日本語などを元の文字に復元します。
   - **Googleサポートページ**（`support.google.com`、コミュニティ除く）: `?` 以降のパラメーターをすべて削除します。
   - **Googleサポート コミュニティ**（`support.google.com/s/community/`）: パラメーターを保持したままデコードします（検索クエリなどが読みやすくなります）。
   - **その他のページ**: 不要な個人パラメーター（`uule`）と言語指定パラメーター（`hl`）のみを除去します。

2. **高度なタイトル抽出ロジック**
   - ページ内の `h1` タグだけでなく、サイト構造に合わせて最適な要素からタイトルを取得します。
   - **Googleサポートページでは、英語（hl=en）・日本語（hl=ja）を指定してタイトル取得が可能です。**
   - **対応サイト例:**
     - **Epson FAQ:** ページ上部のパンくずではなく、具体的な「質問内容」を優先取得。
     - **Yahoo!ニュース:** 記事のメイン見出しを正確に取得。
     - **ESET サポート:** FAQの質問タイトルをピンポイントで取得。
     - **Google Blogspot:** 記事タイトル（h3）に対応。
     - **Google Help:** 言語指定取得および不要パラメータ削除に対応。

3. **Offscreen Document によるコピーと結果表示**
   - ページ内ではタイトル・URLの文字列生成のみを行い、`clipboardWrite` 権限を持つ Offscreen Document がコピーします（Chrome 116以降）。
   - 成功応答後は緑の `OK`、失敗時は赤の `!` を全体バッジに表示し、失敗理由をツールチップに示します。4秒後、または次回操作開始時に `C` と既定タイトルに戻ります。
   - 連続操作では最新の要求を優先します。Googleサポートの言語指定取得は5秒で打ち切り、失敗時は現在ページのタイトルに戻ります。
   - Chrome内部ページやChrome Web Storeなど、注入できないページでは失敗を表示します。

4. **３種類の実行方法**
   - **Cボタン:** ツールバーのアイコン（Cバッジ）をクリック。
   - **コンテキストメニュー（通常）:** 「タイトルとURLをコピー (通常)」
   - **コンテキストメニュー（言語指定）:**  
     - 「タイトル(英)とURLをコピー」  
     - 「タイトル(日)とURLをコピー」

## ファイル構成

- `manifest.json`: 拡張機能の定義ファイル。
- `background.js`: 右クリックメニューの生成、ボタンクリックの検知、ページ内の文字列生成、Offscreen Documentの管理、および結果表示を制御するメインロジック。
- `offscreen.html` / `offscreen.js`: コピーの実行と成否応答。
- `tests/`: Node標準機能によるモック回帰テスト（`node --test tests/`）。

## インストール方法

1. このリポジトリのファイルをすべてダウンロードし、任意のフォルダに展開します。
2. Google Chromeを開き、アドレスバーに `chrome://extensions/` を入力して開きます。
3. 右上の「デベロッパー モード」を **ON** にします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、手順1で展開したフォルダを選択します。
5. ツールバーに「C」のバッジがついたアイコンが表示されれば完了です。

## 使い方

### 方法A：ツールバーのボタン
1. コピーしたいページを開きます。
2. ツールバーの「C」バッジがついた拡張機能アイコンをクリックします。
3. 「[タイトル]\n[クリーンなURL]」の形式でクリップボードに保存されます。

### 方法B：右クリックメニュー
1. ページ上の任意の場所で右クリックします。
2. 以下から選択します。
   - 「タイトルとURLをコピー (通常)」
   - 「タイトル(英)とURLをコピー」
   - 「タイトル(日)とURLをコピー」
